# KSL-65

Controllable paired RGB and 3D keypoint generation for Korean Sign Language handshape classification.

This repository hosts release notes and updates for KSL-65. The generator, assets, and synthetic corpus are distributed through Zenodo (DOI [10.5281/zenodo.23004222](https://doi.org/10.5281/zenodo.23004222)); the record is restricted during peer review and will be made public upon acceptance of the article.

Paper: *KSL-65: Controllable Paired RGB and 3D Keypoint Generation for Korean Sign Language Handshape Classification* (under review, IEEE Access).
