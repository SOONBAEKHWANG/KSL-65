# KSL-65

Controllable paired RGB and 3D keypoint generation for Korean Sign Language handshape classification.

This repository hosts release notes and updates for KSL-65. The generator code and generation assets (rigged hand model, canonical poses, and HDRI maps), together with the synthetic corpus (paired RGB images and Rig20 keypoints) and the per-image manifest, are distributed through Zenodo (DOI [10.5281/zenodo.23004222](https://doi.org/10.5281/zenodo.23004222)); the files in the record are restricted during peer review and will be made public upon acceptance of the article. Upon acceptance, this repository will also be updated to include the code released on Zenodo.

**Note for reviewers:** Thank you for taking the time to review our work. A private access link to the restricted files was provided to the handling editor at submission. If it has not yet reached you, we would be grateful if you could request it from the editor.

**Paper:** *KSL-65: Controllable Paired RGB and 3D Keypoint Generation for Korean Sign Language Handshape Classification* (under review, *IEEE Access*).
